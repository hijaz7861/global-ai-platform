# Project Conversation Context

The project owner wants a global AI-powered business platform built incrementally, with the Master Blueprint documented first.

The owner has requested:
- Web-first development and a shared backend.
- A global marketplace and integrated business modules.
- AI agents coordinated by a central orchestrator.
- A universal connector system for authorized third-party services.
- Multi-provider AI coordination.
- Automated accounting, financial oversight and human approval for high-risk actions.
- A controlled AI research and evolution laboratory.
- Scenario simulations and business analytics.
- Strong security and strict tenant isolation.
- A low-cost, open-source-first strategy.
- Careful testing, failure correction and regression testing before advancing.
- GitHub source control and a private repository.
- Urdu-only communication. Do not translate the owner's messages into Hindi.
- No unapproved spending, public publishing or production deployment.

The repository is intended to preserve the platform vision, requirements, decisions, implementation status and testing evidence.
